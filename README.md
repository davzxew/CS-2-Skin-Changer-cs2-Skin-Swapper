## 📖 What is this?

**CS2-Skin-Changer-Skin-Swapper** swaps weapon, knife and glove skins locally so they show up in your own view — without buying anything.

You pick a weapon, pick a paint kit, then set float, pattern seed and any sticker slots you want. Presets can be saved per weapon and applied in one keypress, so a full loadout takes seconds. Everything is client-side: your inventory stays untouched and other players still see your real skins.

The tool reads memory from outside the process. No injection into the game, no modified files on disk.
